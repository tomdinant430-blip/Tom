# StudySpark

Un mini-site statique pour charger un cours PDF, extraire le texte et générer des quiz/flashcards côté navigateur.

## Lancer le site en local

1. Démarrer un serveur statique depuis la racine du dépôt :

```bash
python -m http.server 8000
```

2. Ouvrir ensuite le navigateur sur :

```
http://localhost:8000
```

## Utilisation

- Cliquez sur **Charger un PDF** pour sélectionner un fichier local.
- Ou cliquez sur **Utiliser une démo** pour voir un exemple immédiat.
