Chaîne d'information

La chaîne d'information d'un système pluri‑technologique reçoit des consignes de l'utilisateur et des mesures de grandeurs physiques. La fonction Acquérir transforme ces grandeurs en signaux exploitables pour la fonction Traiter.

Capteurs : définition

Un capteur prélève une information issue d'une grandeur physique (température, pression, vitesse...). Il fournit une grandeur de sortie, souvent électrique, utilisable pour mesurer ou commander un système.

Grandeur physique Signal de sortie

Caractéristiques d'un capteur

  • Étendue de mesure : valeurs extrêmes mesurables.
  • Résolution : plus petite variation détectable.
  • Sensibilité : variation de la sortie / variation de l'entrée.
  • Précision : proximité entre mesure et valeur vraie.
  • Rapidité : temps de réaction.
  • Linéarité : proportionnalité de la sortie à l'entrée.

Erreurs de mesure

La qualité d'un capteur se juge avec la justesse (écart à la valeur vraie), la fidélité (répétabilité) et la précision (combinaison justesse + fidélité).

Erreur relative : εr = ε / X (souvent en %).

Erreur absolue : ε = x − X.

Capteurs TOR

Les capteurs Tout Ou Rien délivrent un signal binaire (0 ou 1). Ils utilisent souvent un seuil haut et un seuil bas pour éviter l'instabilité (hystérésis).

  • Interrupteur de position
  • Détecteur inductif
  • Détecteur photoélectrique

Capteurs analogiques

Les capteurs proportionnels analogiques produisent un signal continu (0‑10 V, -10/+10 V, 0‑20 mA, 4‑20 mA). La sortie est proportionnelle à la grandeur mesurée.

  • Jauge de contrainte
  • Capteur de température
  • Accéléromètre capacitif

Capteurs numériques

Les capteurs numériques délivrent un code (binaire, Gray...). Exemple : codeur absolu ou incrémental pour la position angulaire.

  • Sortie série ou parallèle
  • Code binaire naturel / Gray
